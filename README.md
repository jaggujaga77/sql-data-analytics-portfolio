# SQL Data Analytics Portfolio

## Project Overview

This project demonstrates SQL skills through data exploration and analysis of COVID-19 datasets. It uses SQL queries to identify trends in cases, deaths, and vaccinations.

## Objectives

* Explore COVID-19 data using SQL.
* Analyze total cases and deaths.
* Calculate death percentages and infection rates.
* Examine vaccination progress.
* Practice data filtering, aggregation, and joins.

## Tools Used

* SQL
* Relational database concepts
* COVID-19 datasets

## Project Files

* `COVID Portfolio Project - Data Exploration.sql` — SQL queries for data exploration.

## Key SQL Concepts

* SELECT and WHERE
* ORDER BY and GROUP BY
* Aggregate functions
* JOIN operations
* Subqueries
* Window functions
